# Dhaval Pandit — Portfolio

A cinematic, responsive portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Preview

Run any static server in this directory, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Updating content

- Main biography, experience, and links: `index.html`
- Case-study modal content: `projects` object at the top of `script.js`
- Colors and typography: CSS variables at the top of `styles.css`

No build step or external JavaScript dependencies are required.
